# FrameCast

FrameCast is a local-first macOS studio for recording an iPhone or iPad in a realistic device frame. It needs no login, adds no watermark and has no subscription.

## Download

**[Download the latest FrameCast](https://github.com/Teseife/FrameCast-releases/releases/latest)**. It runs on macOS 14 or later.

Open the DMG and drag FrameCast to Applications. Every release is signed with a Developer ID and notarized by Apple. FrameCast checks for updates itself, so you only download it once.

## About this repo

This repo only holds the release downloads and `appcast.xml`, the feed FrameCast reads to find updates. The source code lives in a separate repo.
